Notes

4K7 summing on the preamp: 6x 4.7k (one per RX hot) -> sum node -> 100nF -> +IN. NO junction board. 4.7k >> source so pickups stop loading each other (was 6-7x shunt = the ~2x SNR). Sum=/6, x48 covers it.

Gain x48: 47k/1k. ~1-9 mV RX -> ~50-430 mV, clean in +/-1 V. x11 too low (near floor), 1600x clips. x48 is the middle.

ONE stage only: use op-amp A (pins1-3); park half B. Two stages would clip the 100mm modes (the F1-8 "quiet" bug).

No clipper: linear readout - no diodes, no overdrive. Ch B keeps the TX bundle as drive ref.
