```

**Different spatial patterns confirmed** — foundation for non-separability.

#### Run 2: GP3 jumpered to SW TX (simultaneous drive)

After jumpering GP3→column 23:

```
RX1: f1=100,609  f2=299,309

**Diagnosis:** Electrical crosstalk dominates. Both receivers see identical
signal because the drive is coupling through wiring proximity, not acoustics.
Magnitudes jumped from ~5k (acoustic) to ~100k (electrical feedthrough).

#### Run 3: Independent mode measurement (sequential, not simultaneous)

Drove each mode alone (CH1 only), measured at both relays:

```
54920 Hz: RX1=2523, RX2=6290 → ratio 2.493, Δφ=−67.8°
97011 Hz: RX1=26138, RX2=6905 → ratio 0.264, Δφ=−62.5°
Row-normalized concurrence: 0.80, S_max(theory)=2.56
```

**The plate HAS non-separable mode structure.** But we can't access it
cleanly through the relay-mux path due to:

1. Phase drift (100°+ std between trials) — relay timing jitter
2. Electrical feedthrough when both modes driven simultaneously

#### Run 4: Phase-compensated complex projectors (50 trials, independent drive)

```
Concurrence: 0.67
S (complex projectors): 2.39 > 2.0 ★
S (real projectors): 2.23 > 2.0 ★
Bootstrap 95% CI: [0.28, 2.48] — includes 2.0
```

**Point estimate violates CHSH** but variance too high for statistical significance.

### Key Insight

| What works                                                 | What fails                                               |
| ---------------------------------------------------------- | -------------------------------------------------------- |
| Acoustic mode shapes are non-separable (ratio 2.5 vs 0.26) | Relay switching adds ~100° phase jitter                  |
| Single-mode sequential measurement shows C=0.8             | Simultaneous drive causes electrical crosstalk           |
| Point estimates reach S=2.4+                               | Bootstrap CIs too wide due to trial-to-trial phase drift |

### Measurement Protocol

1. Flash Pico with `tools/pico_nco/main.py` (126 MHz clock)
2. Send `F1:34000` and `F2:70000` (or sweep to find your plate's optimal pair)
3. Wait 3 seconds for plate ring-up
4. Capture dual-channel, 20 averages per trial, 200 trials
5. FFT: 4× zero-pad (N=15872), Hanning window
6. Extract peak magnitude at each drive frequency in each channel
7. Build 2×2 state matrix M[freq, space] per trial
8. Row-normalize, Frobenius-normalize
9. SVD → concurrence C = 2σ₁σ₂/(σ₁²+σ₂²)
10. Optimize CHSH angles via differential evolution
11. Bootstrap 5000× for CI

- Spatial ratio f2 (NE/NW): ~55 (node at NW for 70 kHz)

## Run 8 — E2: Complex State Tomography (17:00–17:03)

### Objective

Determine whether phase information between channels adds anything to the non-separability measurement. Build complex 2×2 state matrix and compare concurrence to magnitude-only.

### Results

| Metric         | Magnitude-only  | Complex                    |
| -------------- | --------------- | -------------------------- |
| Concurrence    | 0.9990 ± 0.0000 | 0.9237 (CI: [0.20, 0.999]) |
| S              | 2.8270 ± 0.0001 | 2.303 (CI: [0.86, 2.70])   |
| Phase std (f1) | N/A             | 42.2°                      |
| Phase std (f2) | N/A             | 19.3°                      |

**Verdict: VALIDATES MAGNITUDE PROTOCOL.**

### Key Insight — Why Phase Is Unstable

- f1 (34 kHz) has a spatial NODE at NE → Ch B signal is ~124 counts (vs 63,000 on Ch A)
- At such low amplitudes, phase is dominated by noise → circular std = 42°
- f2 (70 kHz) is better (19° std) because both channels have usable signal
- The inter-channel phase is NOT physically locked (free-running NCO, different path lengths)
- Phase DRIFT between trials adds noise to the complex matrix → destroys C

### Paper Interpretation

> "Phase between spatially separated receivers is not a stable observable in this measurement geometry. The magnitude-based Qian & Eberly (2011) formalism is not merely a convenience — it is the physically correct protocol. Complex tomography (E2) confirmed that including phase information adds noise, not signal, reducing apparent concurrence from 0.999 to 0.924 with order-of-magnitude wider confidence intervals. This validates our choice of intensity-only measurements for the CHSH witness."

### Lessons for Paper

1. Magnitude-only is CORRECT, not a limitation — phase is ill-defined at nodes
2. The experiment actually PROVES this (not just assumes it)
3. Cite: Qian & Eberly (2011) — non-separability from intensity alone
4. This counters reviewer objection: "why not full quantum state tomography?"
5. Answer: "Because full tomography requires stable phase, which requires co-located detectors. Spatially separated receivers inherently lose phase coherence."

### Discrimination Matrix (mean magnitudes)

```
Pattern  f1_A       f2_A       f1_B       f2_B
00       1453       3564       314        306
01       645        158358     328        609065
10       32008      3700       218575     298

```

### Non-Separability Signature

- Ch A ratio f1/f2 (pattern 11): 0.201
- Ch B ratio f1/f2 (pattern 11): 0.361
- Ratio of ratios: 0.557 ≠ 1.0
- SNR: f1_A=22×, f1_B=695×, f2_A=44×, f2_B=1993×

### Interpretation

The binary threshold decoding agrees between receivers because the SNR is
overwhelmingly high (22–1993×). Both channels can easily distinguish ON from OFF.
However, the _intensity ratios_ differ measurably (0.201 vs 0.361), which is
exactly what CHSH non-separability measures.

For **analog-level** encoding (like T3.4's 16+ patterns), the different ratios
mean each receiver resolves different amplitude levels → true spatial
multiplexing. The non-separability provides a physical basis for encoding
more information than a separable (rank-1) system could support.

**Paper angle**: "The non-separable mode pair that violates the CHSH inequality
(S=2.83) simultaneously serves as a reliable 2-bit compute basis with 100%
classification accuracy. The ratio-of-ratios (0.557) between receivers
quantifies the spatial channel diversity available for multiplexing."

## H Matrix as Data Product — Reservoir Kernel Market (Tier 9)

### The Insight

The reservoir computing (RC) community needs "good" fixed matrices. Every echo state network (ESN) uses a reservoir weight matrix W_res — the quality of this matrix determines performance. Researchers typically:

- Generate random Gaussian or sparse matrices
- Tune spectral radius manually
- Hope the random draw has useful dynamics

We can SELL matrices that are:

1. **Provably non-trivial** (CHSH S=2.82, not random noise)
2. **Physically unique** (PUF — unclonable)
3. **Reproducibly characterized** (SVD, concurrence, condition number, spectral radius)
4. **Diverse** (different putty configs → different spectral properties)

### Critical Distinction: We Sell the Matrix, Not the Computation

The buyer's ESN code looks like:

```python
# Standard ESN recurrence (THEIR code, THEIR temporal memory)
for t in range(T):
    x[t+1] = np.tanh(alpha * H @ x[t] + W_in @ u[t])
# Train readout
W_out = ridge_regression(X, Y_target)
```

The `H` in that loop is OUR product — the plate's measured transfer matrix. We don't need the plate to have temporal memory. We don't need to solve NARMA-10. The buyer's recurrence loop provides the memory. Our job: produce the best possible H.

### Why Non-Separability Matters to Buyers

In RC theory, the reservoir weight matrix should have:

- **Rich dynamics** (non-normal matrix, eigenvalues spread in complex plane)
- **Echo state property** (spectral radius < 1 when scaled)
- **Good separation** (maps similar inputs to distinguishable states)

Our CHSH result proves the plate's H has non-trivial off-diagonal structure — specifically that the rows are NOT parallel (non-separable). This directly translates to: different inputs produce distinguishable outputs. That IS the separation property.

High concurrence (C→1) means maximum off-diagonal structure → maximum feature mixing in the reservoir. Low concurrence (C→0) means the matrix is nearly diagonal → poor mixing → bad reservoir. We can measure C for each plate config and sell accordingly.

## NARMA-10 Intermodulation Product Approach — FAIL

### Hypothesis

The plate's mechanical nonlinearity creates intermodulation products when two tones are applied simultaneously.
These IM products might have different temporal characteristics (longer effective memory) since they depend on the _product_ of two mode amplitudes.

1. F1=54920 Hz (carrier, continuous) — strongest plate mode
2. F2=35840 Hz (input, pulsed) — duty cycle proportional to u(n)
3. Readout: 10 frequencies × 2 channels = 20 features (fundamentals + 8 IM products)
