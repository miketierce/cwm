### Comparison with Rayleigh Perturbation Theory

**Prediction:** Δf/f = −Δm·|φ|²/(2·M_eff)

Parameters:

- Δm = 50 mg, M_total = 2.575 g, M_eff = M/4 = 0.644 g
- |φ|² at (1/3, 1/3) = sin²(π/3)·sin²(π/3) = 9/16 = 0.5625
- Predicted: Δf/f = −2.18% (all modes, if simply-supported plate)

**Observed vs Predicted:**

| Mode         | Observed Δf/f  | Predicted Δf/f | Ratio     |
| ------------ | -------------- | -------------- | --------- |
| 86 kHz       | −0.3% to −0.6% | −2.2%          | 0.13–0.28 |
| 91 kHz       | −0.2% to −0.6% | −2.2%          | 0.08–0.27 |
| 232 kHz (NE) | −0.3%          | −2.2%          | 0.15      |

**Key findings:**

1. **Direction correct** — 6/10 measurements shifted DOWN as Rayleigh predicts for mass-loading.
2. **Magnitude 4–12× smaller than simple theory** — expected because:
   - M_eff = M/4 assumes ideal simply-supported plate; our free plate with corner PZT masses has larger effective mass
   - Position A may be closer to a node than theory suggests (PZT mass distorts mode shapes away from ideal sinusoids)
   - Some |φ|² < 9/16 at this position for the actual (non-ideal) modes
3. **Upward shifts (232/321 kHz NW)** — likely mode-hopping: the peak finder locked onto a different nearby mode in the ±3 kHz window. The NW channel shows 232 kHz jumping from 231,150→234,200 Hz (3 kHz leap = suspicious). NE channel tracked the same mode cleanly (232,700→231,950, −750 Hz down).
4. **56 kHz unresolved** — Δf ≈ BW, at measurement noise floor. This mode may be near a node at position A, or the mode shape has low |φ|² there.
5. **86 and 91 kHz are the cleanest demonstration** — both channels agree on direction, shifts are multi-BW, and magnitudes are physically reasonable.

**Conclusion:** Mass perturbation produces measurable, position-dependent spectral fingerprints. The shift pattern (which modes shift, by how much) is unique to the putty position. This validates the core principle of spatial encoding via eigenmode perturbation.

### Ringdown Attempt — Result: NOT CONFIRMED

**Initial attempt** (Q=6750, τ=6.7ms predicted):

- Drove 321 kHz for 200ms, sent Foff, captured 10.3ms window
- Bandpass RMS envelope: 5.4 mV for first 2ms, then cliff to 0.9 mV (noise)
- Exponential fit gave τ=6.7ms, Q=6779 — appeared to agree perfectly with BW method

**Validation tests revealed artifact:**

| Test                         | Setup                              | Result                          | Verdict                       |
| ---------------------------- | ---------------------------------- | ------------------------------- | ----------------------------- |
| NULL (300 kHz off-resonance) | Drive off-resonance, Foff, capture | Same 5 mV / 2ms / cliff pattern | **FAIL** — same as "ringdown" |
| DELAYED (5ms post-Foff)      | Drive 321 kHz, 5ms wait, capture   | Only noise (0.96 mV)            | No detectable signal          |
| REPEAT (0ms, 321 kHz)        | Same as original                   | Same 5.8 mV / cliff pattern     | Reproduces artifact           |

**Root cause:** The NCO `Foff` serial command takes ~2-3ms to execute (serial TX + firmware shutdown). What we captured as "ringdown" was actually the **final 2-3ms of the still-active NCO square wave** propagating through electrical feedthrough, followed by silence.

**Signal budget analysis (why ringdown is undetectable):**

- Mode peak amplitude at f₀: 4.6 mV (during CW drive, measured via narrow FFT bin)
- Mode bandwidth: 48 Hz
- Bandpass width in time-domain capture: ~25 kHz
- Mode RMS contribution to 25kHz bandpass: **0.20 mV** (=4.6 × √(48/25000))
- Noise floor in same bandpass: 0.85 mV
- **SNR = 0.24** — the mode is completely buried in broadband noise

**Why frequency-domain works but time-domain doesn't:**

- FFT-based detection acts as a ~97 Hz (=fs/N_samples) bandwidth filter → SNR = 4.6/0.03 ≈ 150
- Time-domain with 25 kHz bandpass → SNR = 0.24
- Factor of **625× difference** in effective measurement bandwidth

**What would make ringdown work:**

1. Lock-in detection (multiply by cos(2πf₀t), lowpass) → direct envelope extraction
2. ~300 averaged captures (SNR improves by √N)
3. ×10 higher preamp gain (would clip during drive → need relay to disconnect TX during capture)
4. Hardware trigger synchronized to NCO GPIO shutdown (bypass serial latency)

**Conclusion:** The Q=6750 measured via BW method is **valid** (pure frequency-domain, no timing issues). Ringdown measurement requires dedicated hardware (lock-in amplifier or hardware-triggered capture with TX isolation). The Q value already implies τ=6.7ms via the relationship Q=πf₀τ — we just can't directly observe it with current SNR.

### Wire Length Lesson

**Critical finding:** TX wire length dominates coupling efficiency at 30–350 kHz. Shortened wires improved amplitudes 8–260× across all plates. The long wires act as radiating antennas — most drive energy becomes EMI rather than reaching the PZT. For the paper: this is engineering, not physics, but must be controlled for reliable measurements.
