## CORRECTION + fair baselines — the denoising headline was unfair (12:10)
tools/recall_enroll_save.py (R5,navg24 -> recall_enroll_20260629_120542.npz, X 1280×240 = 28 axis + 212 unique mode freqs) + tools/recall_analyze.py. recall_analysis_120542.json.

**Two earlier claims RETRACTED:**
- "256-mode plateau" was a slicing artifact: top-k just sliced rank[:k], and k≥Fd returns the full set. There are only **~212 unique mode freqs** (767 census modes collapse across TX). So "256/512 plateau" = the full bank, not a real optimum.
- "+41 pts denoising vs wire" used an UNFAIR 4-dim wire. Give the wire equal dimensionality (expand the 4 driven bins to 240 random dims = wire_rp) and it WINS:

| σ | wire4 | wire_rp (fair dim) | glass (all) |
|---|---|---|---|
| 0 | 100 | 100 | 97 |
| 1 | 51 | **100** | 88 |
| 2 | 38 | 96 | 74 |
| 3 | 36 | 85 | 64 |

Reason: iid feature-space noise rewards REDUNDANCY — 4 clean high-SNR encoded numbers, replicated, noise-average; 212 distinct modes each carry their own measurement noise. So the glass is NOT a denoiser; a redundant wire denoises better. The σ-in-feature-space model is the wrong test (it favors low intrinsic dim).

**What IS real (survives fair test):**
1. **Partial-query pattern completion** — hide vx,vy in the query, recall landing:
   glass 96/84/59 (σ0/1/3) vs wire4 64/47/36. **+37 pts @σ1.** The modes physically encode the hidden state variables a per-axis readout never measures. Genuine content-addressable memory.
2. **Graceful degradation** — zero a fraction of modes @σ1: drop 0/10/25/50/75/90% -> 88/88/87/85/85/83. **Lose 90% of modes, keep 83%.** Distributed redundancy = dead-sensor tolerance.

**Reframed worth-having claim (defensible): the glass is a content-addressable memory, not a denoiser. Value = (a) completes a partial query by recalling unmeasured state variables, (b) tolerates massive feature/sensor loss. NOT: beats a redundant wire under additive noise.** Next (needs bench): physical noise (drive attenuation/EMI) + physical RX-channel drop to confirm dropout result on real hardware, not feature masking.
