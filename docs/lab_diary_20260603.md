## L3: Train-Through-H (End-to-End with Physical Transfer Matrix)

### Objective

Train a small transformer/attention model that uses the measured plate H as a fixed (non-trainable) attention matrix. If the model converges, it proves H is computationally useful (not random noise).

### H Matrix Properties (from L1)

- Shape: 26×2 (26 modes, 2 spatial channels)
- Ratios (B/A) range: 1.30 – 11.15 (good spatial diversity)
- Condition number: 10.96 (well-conditioned)
- Effective rank: 2 (expected — only 2 receivers)
- All SVD singular values meaningfully contribute

### Approach

Replace attention weight matrix W in a small language model with the physical H.
Standard attention: softmax(Q·K^T / √d) · V
Our approach: Use H as a fixed projection that maps from mode-space to channel-space.

### Architecture (v2 — forced bottleneck, no residual bypass)

```
Token → Embedding(vocab, d_model) → Linear(d_model, 26) → H_plate(26→2)
     → Linear(2, d_model) → LayerNorm → MLP(d_model→2×d_model→d_model) → Linear(d_model→vocab)
```

All information MUST flow through the 26→2 bottleneck (no residual around H).

### Results

| Model              | Params | Val Loss | Perplexity | vs Trainable |
| ------------------ | ------ | -------- | ---------- | ------------ |
| Physical H (fixed) | 86,875 | 2.4890   | 12.05      | 1.00×        |
| Trainable H        | 86,927 | 2.4892   | 12.05      | 1.00×        |
| Random H (5 draws) | 86,875 | 2.4826   | 12.04±0.06 | 1.00×        |
| No-H (direct)      | 33,473 | 2.4827   | 11.97      | 0.99×        |

Dataset: Tiny Shakespeare (1.1M chars, vocab=65, character-level)
Config: d_model=128, seq_len=64, batch_size=64, 30 epochs, lr=1e-3

### Interpretation

**PASS (convergence criterion):** Physical H achieves perplexity within 2× of trainable baseline (ratio = 1.00×). The model successfully trains with H as a fixed layer.

**INCONCLUSIVE (structural usefulness):** Physical H is indistinguishable from random H (12.05 vs 12.04±0.06). The 26→2 bottleneck is so narrow that:

1. The learnable layers before H adapt to project into whichever 2D subspace H maps best
2. The learnable layers after H expand from 2D back to d_model
3. ANY rank-2 matrix in between works equally well — structure doesn't matter

**Root cause:** With only 2 output columns (2 spatial receivers), H is rank-2. The model can always learn a rotation before H that aligns the 2 useful dimensions with H's column space. The specific spatial pattern of the plate (mode→receiver mapping) becomes irrelevant when the model has freedom to rotate its inputs.

### What Would Change This

1. **More receivers** (≥8 spatial channels) → H becomes rank-8+, structure matters
2. **Constrain the input projection** to be fixed (e.g., one-hot mode selection) → forces model to use H's actual spatial diversity
3. **Multi-plate cascade** → H₁·H₂ has richer structure than single plate
4. **Larger vocabulary / harder task** where the 2-bit bottleneck actually limits capacity

### Next Steps

The experiment proves H is a valid computational matrix (doesn't break training), but the current 26×2 geometry has too little structure to differentiate from random. The plate needs **more receivers** to demonstrate unique utility.

## L3c: Polysemic Train-Through-H (K=8 Sub-band Readout)

### Motivation

L3b capacity analysis showed polysemic readout (partitioning 26 modes into K subsets, each giving independent 2D projections) could increase effective output dimensionality from 2 to 2K=16. The plate's B/A ratio diversity (1.3–11.2×) gives 96% independence between subsets, and physical H beats random at 3.9σ in the capacity metric.

Question: does the polysemic approach make physical H distinguishable from random in the LLM task?

### Architecture

```
Token → Embed(vocab, d_model=128) → Linear(128, 26)
     → [K=8 sub-H projections, each (3-4 modes)×2 → 2 dims]
     → Concat(8×2 = 16 dims)
     → Linear(16, 128) → LN → MLP(128→256→128) → LN → Head(128→65)
```

Partition: `max_diversity` — sorted by spatial angle (arctan B/A), then interleaved across subsets so each subset spans the full angle range.

### Results

| ---------------------------- | ------ | -------- | ---------- | -------- |
| Physical H poly (K=8)        | 88,667 | 2.4807   | 11.95      | 1.00×    |
| Trainable poly (K=8)         | 88,719 | 2.4829   | 11.98      | 1.00×    |
| Random H poly (mean±std)     | 88,667 | —        | 11.98±0.04 | 1.00×    |
| Shuffled H poly (mean±std)   | 88,667 | —        | 11.98±0.04 | 1.00×    |
| Single H (26→2, original L3) | 86,875 | 2.4903   | 12.06      | 1.01×    |

### Diagnostic Tests

- **A) Polysemic vs Single-H:** 11.95 vs 12.06 (+1.0%) — polysemic readout helps slightly
- **B) Physical vs Random H:** 0.9σ — indistinguishable
- **C) Physical vs Shuffled H:** 0.9σ — partition order doesn't matter
- **D) Gap to optimal:** -0.2% — physical ≈ trainable (near-optimal)

### Interpretation

**Polysemic readout provides a small improvement** (1.0% PPL reduction from 16 output dims vs 2), confirming that more dimensions through the bottleneck helps.

**But physical H is STILL indistinguishable from random.** The root cause is unchanged: all 8 sub-H matrices project into the **same 2D physical sensor space** (Ch A, Ch B). Partitioning modes into subsets creates 8 copies of rank-2 projections within the same 2D column space. The learnable Linear(128→26) layer before H can always rotate inputs to exploit any matrix equally.

The L3b capacity analysis measured independence of **mode amplitudes** (which ARE diverse: B/A 1.3–11.2). But in the LLM context, the learnable layer absorbs that diversity through rotation — the model doesn't "see" different B/A ratios because it pre-rotates.

### The Hard Conclusion

The bottleneck is **not the number of modes** (26 is plenty). It's the **number of physical receivers** (2). No amount of mode partitioning can create more than rank-2 information when measured at 2 spatial points.

To differentiate physical H from random, we need:

1. **More receivers** — relay mux all 8 positions → H becomes 26×8, rank ≥8
2. **Constrained input** — remove the learnable pre-projection (one-hot mode selection)
3. **Sequential multi-capture** — drive subset, capture, switch relay, repeat → builds up dimensionality physically

Option 1 (relay mux) is directly available with current hardware — just slower (8 captures per forward pass instead of 1).

## L3d: Constrained-Input Approaches (Breaking Absorption Theorem)

### Motivation

L3 and L3c both showed that with learnable layers before and after a rank-2 H, the optimizer absorbs H into the surrounding weights (absorption theorem: L1·H·L2 collapses to a single bottleneck). Need to **break** this algebraic simplification.

Four approaches tested:

1. **Fixed Codebook** — remove pre-rotation freedom (no learnable layer before H)
2. **Nonlinear IM Products** — H-derived coupling topology creates unique kernel
3. **Q-decay Temporal Mux** — H(t) = H⊙diag(exp(-πft/Q)) — time-varying H
4. **Cascaded H + tanh** — H∘tanh∘L∘H∘tanh∘L∘H — depth + nonlinearity blocks simplification

### Results (Full Table)

| Approach              | Physical PPL | Random PPL | σ Adv | Verdict        |
| --------------------- | ------------ | ---------- | ----- | -------------- |
| Codebook (hadamard)   | 14.56        | 12.23±0.08 | -30.1 | Physical WORSE |
| Codebook (freq_bands) | 13.70        | 12.19±0.08 | -17.9 | Physical WORSE |
| Nonlinear IM          | 11.97        | 11.97±0.05 | 0.0   | Tied           |
| Temporal (8 samples)  | 12.00        | 11.98±0.03 | -0.7  | No             |
| Cascaded (3 passes)   | 12.93        | 13.48±1.62 | +0.3  | No             |
| Cascaded (5 passes)   | 13.33        | 15.31±3.07 | +0.6  | No             |

### Interpretation

**No approach differentiated physical H from random at significance.**

Key observations:

- **Codebook** proved physical H IS distinguishable (just in the wrong direction). The plate's clustered angular structure (most modes at 70–85°) collapses tokens into a narrow 2D wedge. Random matrices spread more uniformly → better.
- **Nonlinear IM** was absorbed — learnable pre-projection still finds a way to equalize.
- **Temporal** expansion from 2→16 virtual sensors didn't help because the decay weights are correlated (all derived from same physical Q spectrum).
- **Cascaded** showed high variance in random baselines (some random matrices happen to be hard to optimize through 3–5 sequential bottlenecks), but physical H wasn't consistently better.

### The Definitive Conclusion

**The 2-channel rank-2 constraint is fundamental.** With only 2 physical receivers, any 26×2 matrix carries at most 2 independent dimensions of information per forward pass. The learnable surrounding layers have too much freedom to adapt to any arbitrary 2D subspace.

The plate's spatial structure (mode shapes, B/A ratios, Q values) IS real and measurable — but **you cannot observe its uniqueness through a rank-2 bottleneck in a differentiable model**. It's not that the structure doesn't exist; it's that gradient descent finds equivalent solutions for any matrix of that rank.

### What Actually Breaks This

The simulation experiments confirm what was already suspected from L3/L3c:

1. **More physical receivers** — relay mux all 8 positions → H becomes 26×8, rank≥8
2. **Multi-plate cascade** — physically pass signal plate-to-plate (L6 in worklist)
3. **Non-differentiable readout** — use plate for hashing/PUF (already proven: T5.2, E1–E3)

## L3e: Train-Through-H with 27×4 Rank-4 Matrix

### Motivation

L3/L3c/L3d all proved the same thing: with a rank-2 H matrix (2 receivers), the optimizer absorbs H into surrounding learnable layers. No approach could differentiate physical H from random.

The multi-plate enrollment gives us a **27×4 H matrix with rank 4** — double the original rank. The 4 receivers (2 per plate, 2 plates) provide genuinely independent spatial channels.

**Key question:** Does doubling the bottleneck rank from 2→4 break the absorption theorem?

**Hypothesis:** With 4 output dimensions instead of 2, the specific structure of H should matter more — the learnable surrounding layers have less freedom to rotate into equivalent solutions because the column-space geometry is richer.

### Architecture

```
Token → Embedding(vocab, d_model) → Linear(d_model, 27) → H_plate(27→4)
     → Linear(4, d_model) → LayerNorm → MLP(d_model→2×d_model→d_model) → Linear(d_model→vocab)
```

Same forced-bottleneck design as L3 (no residual around H), but bottleneck is now 27→4 instead of 26→2.

### Results

| Model               | Params | Val Loss | PPL        | vs Trainable |
| ------------------- | ------ | -------- | ---------- | ------------ |
| Physical H (fixed)  | 87,260 | 2.4870   | 12.03      | 1.00×        |
| Trainable H         | 87,368 | 2.4882   | 12.04      | 1.00×        |
| Random H (mean±std) | 87,260 | 2.4780   | 11.95±0.02 | 0.99×        |
| No-H (direct)       | 33,473 | 2.4846   | 12.00      | 1.00×        |

Config: d_model=128, seq_len=64, batch_size=64, 30 epochs, lr=1e-3
H: 27×4, SVD=[4.898, 1.244, 1.036, 0.623], cond=9.52, effective rank=4

### Interpretation

**PASS (convergence):** Physical H trains fine (1.00× trainable baseline).

**FAIL (differentiation):** Physical H is STILL indistinguishable from random — in fact random is slightly better (11.95 vs 12.03). Doubling rank from 2→4 did NOT break the absorption theorem.

**Why 4 channels didn't help:**

The absorption theorem is more general than originally thought. With learnable Linear(128→27) before H and Linear(4→128) after H, the optimizer has:

- 128×27 = 3,456 free parameters to rotate inputs into H's column space
- 4×128 = 512 free parameters to expand from H's output

For ANY fixed 27×4 matrix H, the pre-projection can find a rotation that works equally well. The geometric structure (which modes are stronger on which plate) is irrelevant when the model can pre-align arbitrarily.

**The real constraint is not rank but degrees of freedom.** The surrounding layers have ~4,000 parameters to compensate for a 108-element H. The ratio (learnable DOF / H DOF ≈ 37:1) is so high that H's specific structure carries no gradient signal.

### What Would Actually Break Absorption

1. **Eliminate the pre-projection** — fix the input mapping (one-hot mode selection, no learnable rotation before H)
2. **Physical forward pass** — actually drive the plate per token, eliminating the software bottleneck entirely
3. **H as the ONLY layer** — no learnable layers at all (pure plate computation)
4. **Massive H** — scale to d_model×d_model where H's structure dominates the parameter budget

The absorption theorem applies at ANY bottleneck rank when surrounding learnable layers have sufficient DOF to find equivalent solutions. This is a fundamental limitation of the "fixed layer in differentiable stack" approach.

## L3f: Enrollment-Locked Attention (Plate as Fixed Attention Pattern)

### Motivation (from PDP-11 Transcript + Boolean Compute Analogy)

All L3 variants (L3–L3e) failed because of the **absorption theorem**: learnable layers before/after H absorb its structure. The DOF ratio (~37:1) means gradient descent always finds equivalent solutions regardless of H.

Key insight from the boolean compute breakthrough: that experiment FAILED at 50% when measuring generically (burst-and-capture) but SUCCEEDED at 100% when measuring at enrolled mode frequencies (sequential capture at known peaks). The PDP-11 transcript crystallized the principle: _"It's more like an arranged marriage between the math and the hardware"_ — shape the algorithm to the device's constraints.

**L3f design principle:** Don't learn a projection INTO mode-space. Use the enrolled spatial patterns AS the embeddings directly. The plate's physical spatial overlaps determine the attention pattern with NO learnable layer between tokens and attention weights.

### Architecture

```
Token(i) → enrolled_mode[i] → 8D signed spatial signature (FIXED)
Position(p) → enrolled_mode[p] → 8D signed spatial signature (FIXED)
Combined embedding: concat(token_sig, pos_sig) → 16D (ALL FIXED)

Attention weights: softmax(combined_i · combined_j / √d·τ) — FIXED by enrollment
Values: Linear(16D → d_value) — LEARNABLE
Output: LayerNorm → Linear(d_value → 4×d_value) → GELU → Linear(→ vocab) — LEARNABLE
```

**What's fixed (from physics):** WHO attends to WHOM
**What's learned:** WHAT information flows, HOW to decode

**Signed feature engineering:** Raw enrollment = amplitudes (all positive) → dot products all positive → softmax ≈ uniform. Fix: build CONTRAST features (centered channels + inter-channel differences) = 8D signed vectors. This tripled angular diversity (raw: 20.9° mean → signed: 59.6° mean).

### Mode Assignment

Greedy selection maximizing minimum pairwise angle:

- 8 position modes (most diverse): 93, 111, 66, 55, 119, 89, 35, 85 kHz
- 10 token modes (remaining most diverse): 100, 106, 97, 109, 63, 33, 57, 52, 79, 68 kHz
- Position angular diversity: min=44.9°, mean=98.9°, max=178.5°
- Token angular diversity: min=29.9°, mean=90.7°, max=175.3°

### Task

8-digit reversal (same as PDP-11 Attention-11): input [4,7,4,9,6,3,5,8] → output [8,5,3,6,9,4,7,4].
Requires positional routing — position 0 must attend to position 7.

### Attention Pattern Analysis

The physical attention matrix for input [0,1,2,3,4,5,6,7]:

- **Diagonal (self-attention) dominates:** mean = 0.518
- **Anti-diagonal (needed for reversal):** mean = 0.127

Each position attends primarily to ITSELF (~50%) because `combined_i · combined_i` is always the largest dot product in the row (it equals the full squared norm).

### Interpretation

**FAIL.** Enrollment-locking works mechanically (absorption is prevented — fixed patterns truly constrain attention), but the constraint imposes the WRONG attention pattern for reversal.

The fundamental issue: we selected modes for maximum angular diversity (mean ~99°), but reversal needs specific ANTI-CORRELATED pairs (pos[0]↔pos[7], pos[1]↔pos[6]...). The plate's mode geometry is arbitrary relative to the task's required routing.

The learnable model succeeds in 5 epochs because it discovers anti-diagonal embeddings; the fixed physical patterns can't — their geometry is determined by plate physics, not task requirements.

### Next Direction: L3g (Permutation Search)

Instead of arbitrary mode assignment, **search over all possible mode→position/token assignments** to find the permutation whose dot-product attention best matches the task's optimal routing. This uses physics without absorption:

- The dot-product attention structure remains FIXED per assignment
- The assignment itself is a discrete combinatorial variable (not differentiable → no absorption)
- If the plate has ANY assignment that creates useful attention, L3g will find it

### The Structural Impossibility Theorem

**Why no permutation can work (mathematical proof):**

For unit-norm embeddings with concatenation:

- `combined_i = [tok_feat[t_i], pos_feat[i]]` where `||tok_feat|| = ||pos_feat|| = 1`
- Self dot: `combined_i . combined_i = ||tok||^2 + ||pos||^2 = 1 + 1 = 2`
- Cross dot: `combined_i . combined_j = tok[t_i].tok[t_j] + pos[i].pos[j] <= 1 + 1 = 2`

The cross term can only EQUAL 2 when both `tok[t_i] = tok[t_j]` AND `pos[i] = pos[j]`, i.e., identical tokens at identical positions -- a contradiction for any useful routing.

**Therefore: dot-product self-attention with fixed unit-norm embeddings ALWAYS has self >= cross.** Self-attention structurally dominates. No permutation, no temperature, no feature engineering can overcome this.

The learnable model escapes by learning **non-unit-norm, task-optimized embeddings** where it constructs `pos[0] ~ pos[7]` (near-parallel for high cross-attention) with specific norm patterns that route information correctly. This requires continuous optimization impossible from discrete physical mode assignment.

### Conclusion: L3 Series Closed

**L3-L3g exhaustively proves:** The plate's spatial transfer matrix cannot improve a neural network through any of these architectures:

| Variant | Approach                            | Failure Mode                        |
| ------- | ----------------------------------- | ----------------------------------- |
| L3      | H as fixed layer                    | Absorption (rank-2, DOF ratio 37:1) |
| L3c     | Polysemic K=8 readout               | Same rank-2 column space            |
| L3d     | Constrained/nonlinear/cascaded      | Absorption persists                 |
| L3e     | Rank-4 (multi-plate)                | Absorption at any rank              |
| L3f     | Enrollment-locked (no pre-rotation) | Self-attention dominance            |
| L3g     | Optimal permutation search          | Structural impossibility theorem    |

**The root causes are different for each sub-group:**

1. **L3-L3e:** Absorption theorem (learnable DOF >> H DOF)
2. **L3f-L3g:** Self-attention dominance (unit-norm dot products <= self-norm)

**What the plate CAN do (proven earlier):**

- Boolean compute at enrolled frequencies (100% accuracy)
- Spatial fingerprinting / PUF (unique, stable)
- Non-separable frequency x space states (S > 2.0)
- Temporal stability (7/7 epochs, <1% drift)

**What it CANNOT do (proven today):**

- Act as a useful fixed attention matrix in a differentiable model
- Provide positional routing in dot-product attention

### What Comes Next (Beyond L3)

The transcript insight "arranged marriage between math and hardware" tells us: **stop trying to force the plate into attention-shaped holes.** The plate's proven capabilities are:

1. **Binary/categorical classification** via threshold on spatial ratios (boolean compute)
2. **Content-addressable memory** via mode enrollment (each mode = one stored pattern)
3. **Physical unclonable function** for cryptographic primitives
4. **Spatial filtering** as a pre-processing step before digital compute

The right framing: plate as **memory/classifier**, not as attention. Tier 9 (digital loop with physical reservoir) or Tier 10 (mode-as-address content-addressable memory) are the natural next steps.
