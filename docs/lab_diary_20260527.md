## Key Learnings

### 1. The Plate's Information Capacity is 12+ Bits Per Observation

With 8 levels per mode and 4 modes, the conservative capacity is 8⁴ = 4,096 patterns = 12 bits. The minimum separation (9σ) suggests even more levels are achievable — the dynamic range supports ~27 levels/mode (9σ / 3σ-per-level criterion), giving 27⁴ ≈ 531k patterns ≈ 19 bits theoretical max.

### 2. Classifier Choice Matters for Combinatorial Class Structures

Ridge regression fails catastrophically when n_classes >> n_features because the one-hot target encoding creates a rank-deficient system. For grid-structured classes (like L^M patterns from multi-level/multi-mode encoding), per-mode independent classification or nearest-centroid are the correct approaches.

### 3. Phase A Data IS the Ground Truth

Phase B's failure doesn't invalidate the measurement — Phase A independently proves each mode supports 8 levels with zero error and 9σ+ separation. Since T2.2/T2.3 proved mode independence (zero crosstalk), the combined capacity is the product by construction.

### 4. Paper Impact

T3.4 directly validates the paper's §11.5 capacity claim: "a single 2.6 ms capture encodes multiple bits per mode." The result (12 bits from 4 modes, extensible to 19+ with finer drive levels) strongly supports the paper's scaling argument: at MEMS scale with 161+ modes, capacity would be 161 × 3 bits/mode ≈ 483 bits per observation.

## Critical Analysis — What T4.1/T4.2 Actually Prove (and Don't Prove)

### What They Prove

1. **The plate CAN serve as a matrix multiply engine.** The measured H is physically real, derived from acoustic resonance, and produces correct attention computation.
2. **Hardware-in-the-loop inference works.** A model trained digitally runs inference through a physical substrate and generates correct output.
3. **The plate's mode isolation is exceptional.** Off-diagonal coupling of 0.25% exceeds our synthetic model's prediction (2.7%).

### What They DON'T Prove

**The plate adds zero computational value over software.** With H ≈ I (off-diagonal 0.0025), routing vectors through the plate is indistinguishable from not routing them at all. The +0.4% accuracy difference is noise. Any task — sorting, reversal, text generation — will produce identical results because H·x ≈ x.

This is the fundamental limitation: the plate's mode orthogonality (which is excellent for memory/encoding) is exactly what makes it useless as a compute element. A near-identity matrix doesn't transform anything.

### The Honest Framing

T4.1/T4.2 demonstrate that the plate is a **valid physical substrate for neural network inference** (the matrix multiply happens in physics, not transistors). But they do NOT demonstrate that it's **useful** for neural network inference — because H ≈ I means it adds nothing that software doesn't already provide cheaper.

### What Would Make It Genuinely Useful

| Path                      | What Changes                                        | Why It Helps                                                                 |
| ------------------------- | --------------------------------------------------- | ---------------------------------------------------------------------------- |
| **Scale modes (60+)**     | Use wider bandwidth (Kronos: 49-67 modes/plate)     | 60×60 multiply is genuinely expensive digitally; plate does it in ~μs at ~nW |
| **Engineer H ≠ I**        | Mass loading, plate coupling, asymmetric geometry   | Non-trivial H computes a transformation software would need O(n²) FLOPS for  |
| **Multi-plate ensemble**  | Use 5 plates as 5 attention heads                   | Each plate has different H → genuine multi-head diversity                    |
| **Exploit temporal axis** | Fix electrical isolation (→ acoustic fraction >60%) | τ=24.5ms memory gives free recurrence — plate becomes an RNN cell            |
| **Fingerprinting/PUF**    | Different task entirely                             | Plate's UNIQUE H is the value (unforgeable physical identity)                |

### Analogy to Optical Neural Networks

This result mirrors exactly what photonic computing papers show: the optical/acoustic substrate provides matrix multiply at O(1) energy, but the matrix itself is typically close to unitary (like our near-identity H). The value proposition is energy/speed at scale, not computational novelty at 4×4.

## T5.2a — CHSH Classical Entanglement, First Attempt (17:06)

### Configuration
- DDS1 @ 35,840 Hz (Alice), DDS2 @ 97,011 Hz (Bob)
- Alice angles: {0°, 45°}, Bob angles: {22.5°, 67.5°}
- Receivers: relay 8 (NE, 5.4×/9.3× SNR) + relay 7 (SW, 3.2×/6.5× SNR)
- 30 trials/setting, 12 spectral averages, 300 ms settle

### Phase Control Validation
- 0° → 180° command: measured 174.9° shift (confirmed working)
- Magnitude ratio at 180°: 0.28 — phase changes spatial interference pattern significantly
- This shows phase-dependent standing wave structure on plate

### CHSH Results

| Setting (Alice°, Bob°) | E ± σ |
|------------------------|-------|
| (0, 22.5)   | +0.067 ± 0.182 |
| (0, 67.5)   | +0.000 ± 0.183 |
| (45, 22.5)  | −0.067 ± 0.182 |
| (45, 67.5)  | +0.200 ± 0.179 |

**S = 0.20 ± 0.36** — well below classical bound of 2.

Baseline (DDS1 only): S = 0.80 ± 0.60

### Interpretation
- All correlations consistent with zero — modes are separable
- Consistent with T2.2 (no intermodulation): linear plate = independent modes
- Phase control works but spatial interference pattern doesn't create CHSH-type correlations with these angles/modes
- Retry: different mode pairs, higher averaging, explore if spatial diversity between RX positions is sufficient

### T5.2b Multi-Pair Sweep (~17:15)

Ran all 4 viable mode pairs (35840+97011, 35840+54920, 54920+97011, 35840+57037) with 50 trials, 20 averages. First pair: S = 0.36 ± 0.28. Second pair SNR too low (f2=2.0×). All results well below S=2.

### Root Cause Analysis: Signal Path Problem

**Key insight:** Both DDS1 and DDS2 outputs are summed through 10kΩ resistors into a **single PZT** (SW corner, via Board D). The CHSH test requires spatial non-separability — the plate's response must depend on *which source* drove it from *which position*. With both sources at the same spatial point:

$$|\psi\rangle = (|f_1\rangle + |f_2\rangle) \otimes |P_{SW}\rangle$$

This is always a product state. S must be ≈ 0 regardless of phase settings, averaging, or mode pair choice.

**Analogy to enrollment fix:** Same class of error as T3.1 parity failure — the signal path didn't support the measurement being attempted. Previous fix: prescan enrollment to filter weak modes. This fix: split DDS outputs to separate PZTs.

### Decision: Dual-TX Rewire Required

- T5.2 (CHSH), T5.3 (nonreciprocal), T5.5 (sync threshold) all require spatially distinct TX positions
- OPA2134PA on Board D is a dual op-amp; Channel A (pins 1,2,3) is unused
- Rewire plan: DDS1 → Board D Ch B → SW PZT (existing), DDS2 → Board D Ch A → 2nd PZT (NE or NW)
- T5.2 status: BLOCKED pending dual-TX rewire
